# 🧬 Аминокислотное Выравнивание

Инструмент для визуализации выравнивания аминокислотных последовательностей с поддержкой поиска, копирования фрагментов и цветовой раскраски по свойствам аминокислот.

## 📌 Описание

Это SPA (одностраничное приложение), написанное на **TypeScript** с использованием **React** и **Vite**, которое позволяет:
- Вводить две аминокислотные последовательности.
- Проверять их на корректность формата.
- Отображать выравнивание с цветовой раскраской.
- Подсвечивать различия во второй строке.
- Искать через `Ctrl+F` / `Cmd+F`.
- Копировать выделенные фрагменты с тостером.

---

## ✅ Технические особенности

- **Фреймворк**: React + TypeScript  
- **Сборщик**: Vite  
- **Стили**: styled-components  
- **Без UI-библиотек**: всё написано своими компонентами  
- **Адаптивный дизайн**: работает на экранах от 320px  

---

## 🎨 Цветовая схема аминокислот

| Символ | Аминокислота     | Цвет        |
|--------|------------------|-------------|
| C      | Цистеин          | `#FFEA00`   |
| G      | Глицин           | `#C4C4C4`   |
| A, I, L, M, W, Y, V, P | Гидрофобные | `#67e4a6` |
| D, E   | Отрицательно заряженные | `#fc9cac` |
| K, R   | Положительно заряженные | `#BB99FF` |
| S, T, H, Q, N | Полярные незаряженные | `#80BFFF` |

---

## 🔍 Возможности

- Валидация формата: только разрешённые символы и одинаковая длина последовательностей  
- Анимированный тостер о копировании  
- Поддержка поиска через `Ctrl+F`  
- Адаптивное отображение последовательностей  
- Кастомная подсветка отличающихся символов

## 📦 Установка и запуск

```bash
# Клонируем репозиторий
git clone https://github.com/NicolayPages/bio-alignment-tool.git
cd bio-alignment-tool

# Устанавливаем зависимости
npm install

# Запускаем локальный сервер
npm run dev
```

Открой [http://localhost:5173](http://localhost:5173) в браузере, чтобы увидеть результат.
